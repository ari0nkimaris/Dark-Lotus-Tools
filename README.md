## 🎭 About

**Dark Lotus Tools** is a Windows Batch script designed as a **TikTok Engagement Bot**. It combines proxy rotation, HTTP requests, and a colorful CMD interface to simulate engagement injection on TikTok videos.

> ⚠️ **Disclaimer:** This tool is for **educational purposes only**. It demonstrates batch scripting, ANSI colors, proxy rotation, and HTTP requests. Usage for actual engagement manipulation violates TikTok's Terms of Service.
